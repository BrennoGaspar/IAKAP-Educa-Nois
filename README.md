# 📚 IAKAP Educa Nóis

Sistema de gestão educacional, desenvolvido com foco em modernizar e simplificar processos escolares através de uma plataforma web intuitiva e centralizada para a ONG Iakap – Instituição Allan Kardec – Alice Pereira.

O projeto tem como objetivo auxiliar no gerenciamento de informações acadêmicas e administrativas, tornando tarefas do dia a dia mais organizadas, rápidas e acessíveis.

---

## 🚀 Objetivo

O IAKAP Educa Nóis busca resolver problemas comuns presentes na gestão escolar, como:

- excesso de burocracia;
- descentralização de informações;
- dificuldade no gerenciamento acadêmico;
- processos manuais demorados;
- organização limitada de dados escolares.

A proposta é oferecer uma solução digital simples e eficiente para melhorar a experiência administrativa e educacional.

---

## 🛠️ Tecnologias Utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- Git
- GitHub

---

## ✨ Funcionalidades

- Cadastro de alunos
- Cadastro de matérias
- Organização acadêmica
- Gerenciamento de informações escolares
- Interface web responsiva
- Centralização de dados educacionais
- Navegação simples e intuitiva

---

## 🎯 Visão do Projeto

Este projeto foi desenvolvido com o propósito de aplicar conceitos de desenvolvimento web em um contexto real de gestão educacional, demonstrando como soluções digitais podem tornar processos escolares e cotidianos mais eficientes e organizados.
